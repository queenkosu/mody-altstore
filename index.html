iPhone でこのページを開く

パソコンで見ている場合は、iPhone のカメラでこのコードを読み取ってください。手順のボタンは iPhone で押します。

入れる前に

  • App Store のアプリではありません。自分の Apple ID（無料）で署名して入れます。
  • 最初の1回だけ、パソコン（Windows / Mac）と USB ケーブルが必要です。
  • 無料の Apple ID で入れたアプリは7日で期限が切れるので、7日以内に SideStore で「更新」します（iPhone だけでできます）。

1SideStore を入れる（最初の1回だけ）

SideStore は、自分の Apple ID でアプリを入れて、7日ごとの更新を iPhone だけでできるようにするアプリです。

  1. iPhone にパスコードを設定し、App Store から LocalDevVPN を入れる
  2. パソコンに iloader を入れ、iPhone を USB ケーブルでつなぐ
  3. iloader で Apple ID にサインインし、SideStore をインストールする
  4. iPhone の 設定 → 一般 → VPNとデバイス管理 で、自分の Apple ID を「信頼」する
  5. iOS 16 以降は 設定 → プライバシーとセキュリティ → デベロッパモード をオンにする

細かい手順は SideStore の公式ガイドに沿って進めてください。

2Mody の配布元を追加する

iPhone でこのボタンを押すと、SideStore が開いて Mody の配布元が追加されます。

SideStore に追加する

ボタンで開かないときは、下の URL をコピーして、SideStore の Sources → 右上の ＋ に貼り付けてください。

SideStore を入れる前にボタンを押すと、何も起きないか SideStore がエラーになります。先に手順1を済ませてください。

3Mody をインストールする

  1. LocalDevVPN を開いて、VPN をオンにする
  2. SideStore の Sources から Mody を開き、FREE をタップする
  3. ホーム画面に Mody が出たら完了

インストール・更新・アップデートのときは、いつも LocalDevVPN をオンにします。

4はじめて開く

  • 大学の ID とパスワードでログインします（パスワードは保存されません）。
  • 通知を許可すると、期限の前やお知らせが届いたときに通知されます。

7日ごとの更新

LocalDevVPN をオンにして、SideStore の My Apps → Refresh All をタップします。残りの日数も My Apps で確認できます。

期限が切れると Mody が開かなくなりますが、データは消えません。更新すればまた使えます。

アップデート

困ったとき

ボタンを押しても何も起きない

SideStore（AltStore）が入っていないか、開けない状態です。手順1を済ませてから押すか、URL をコピーして手動で追加してください。

「信頼されていないデベロッパ」と出て開けない

設定 → 一般 → VPNとデバイス管理 で、自分の Apple ID を「信頼」してください。

急に Mody が開かなくなった

7日の期限が切れています。LocalDevVPN をオンにして、SideStore の My Apps → Refresh All をタップしてください。データはそのまま残っています。

「これ以上アプリを入れられない」と出る

無料の Apple ID で入れられるアプリは1台に3個までです（SideStore 自体も1個に数えます）。使っていないものを SideStore から外してください。

ログインできない

大学の ID とパスワードを確かめてください。Moodle のサイトは年度ごとに変わる（moodle2026 → moodle2027…）ので、ログイン画面の URL が今の年度のものになっているかも確認してください。
